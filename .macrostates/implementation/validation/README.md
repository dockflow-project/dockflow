# Qualification records

These files summarize historical checks, their environment and their limits.
They are not a claim that the current source has been rerun against every
recorded environment. Current behavior is described in
[the implementation overview](../main.md).

Records were anonymized for publication on 2026-10-21. Personal attribution,
machine-specific paths, unrelated project identities and out-of-repository
source inventories were removed. Integration names were normalized to generic
fixture labels. `<fixture>` and `<temporary-file>` are descriptive placeholders,
not real locations or runnable URI authorities. Relative artifact paths preserve
the relationships relevant to the recorded checks.

Measured outcomes, dates, counts and original content hashes remain historical
observations. A hash in an older receipt identifies the bytes measured then; it
does not identify this rewritten receipt, a renamed fixture or current source.
No identity-to-placeholder map or unsanitized copy is retained. Raw scratch
fixtures, screenshots and obsolete build archives were discarded. References
to their paths or hashes document past observations, not available downloads.

Validation performed for the cleanup is recorded separately in
[publication-anonymization.json](publication-anonymization.json). A future release
needs new qualification bound to its exact source and artifacts.
